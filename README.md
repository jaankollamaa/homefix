# HomeFix – Household Maintenance and Repair Tracker

## 1. Project Name

**HomeFix – Household Maintenance and Repair Tracker**

HomeFix is a web application designed to help users organize and manage household appliances, maintenance schedules and repair history.

## 2. Project Purpose

The purpose of HomeFix is to provide a centralized place where users can manage information about their household appliances and keep track of their maintenance.

Many households own several appliances, such as washing machines, dishwashers, refrigerators and ovens. However, information about their maintenance, repairs and purchase details is often scattered across different documents or simply forgotten.

HomeFix aims to solve this problem by allowing users to register appliances, document repairs, schedule maintenance tasks and keep a complete history for each appliance.

The main goal is to make household maintenance easier to organize and help users extend the lifespan of their appliances through better maintenance management.

## 3. Target Audience

The application is intended for:

- Homeowners who want to manage their household appliances.
- People living in apartments who want to keep track of maintenance.
- Tenants who want to document appliance conditions and repairs.
- Landlords who manage appliances in rental properties.
- Anyone who wants to organize household maintenance information in one place.

## 4. Functionality

The application will include the following features:

### 4.1 Appliance Management
- Add new household appliances.
- Enter appliance names, brands, models and purchase dates.
- View a list of registered appliances.
- Edit or delete appliance information.

### 4.2 Maintenance Tracking
- Create maintenance tasks for individual appliances.
- Set maintenance descriptions and due dates.
- View upcoming and overdue maintenance tasks.
- Mark maintenance tasks as completed.

### 4.3 Repair History
- Record appliance problems and malfunctions.
- Add descriptions of repairs and troubleshooting activities.
- Record repair dates and associated costs.
- View previous repair records.

### 4.4 Dashboard
- Display the total number of registered appliances.
- Show upcoming maintenance tasks.
- Highlight overdue maintenance tasks.
- Display recently completed repairs and maintenance activities.

### 4.5 Data Storage
- Save appliance information and maintenance records.
- Retrieve previously saved information.
- Ensure that data remains available after refreshing or reopening the application.

## 5. Technologies

The following technologies and tools are planned for the development:

| Technology | Purpose |
|---|---|
| HTML | Creating the structure of the application. |
| CSS | Styling and designing the user interface. |
| JavaScript | Implementing application functionality and logic. |
| LocalStorage | Storing user data locally in the browser. |
| Git | Tracking changes and managing source code versions. |
| GitHub | Hosting the source code and project documentation. |
| Visual Studio Code | Development environment. |

The initial version will use HTML, CSS and JavaScript without requiring a backend server or external database.

LocalStorage will be used to save information directly in the browser.

LocalStorage keeps data only in one browser on one device. It is not encrypted, not backed up, and the data is lost if the user clears the browser's site data. For this reason, HomeFix is not a secure cloud storage solution.

## 6. Implementation Plan

The development process will be divided into the following stages:

### Phase 1 – Planning and Design
- Define the application structure and functionality.
- Identify the main user requirements.
- Design a basic user interface and navigation.

### Phase 2 – User Interface Development
- Create the main application layout.
- Implement navigation between sections.
- Design appliance management forms and dashboard elements.
- Make the interface responsive for different screen sizes.

### Phase 3 – Core Functionality
- Implement appliance registration and management.
- Develop maintenance task creation and tracking.
- Implement repair history functionality.
- Add dashboard statistics and summaries.

### Phase 4 – Data Storage
- Implement LocalStorage.
- Ensure that user information is saved and retrieved correctly.
- Test data persistence after refreshing the browser.

### Phase 5 – Testing and Improvements
- Test all implemented features.
- Fix errors and unexpected behavior.
- Validate user input.
- Improve usability and responsive design.

### Phase 6 – Finalization
- Review the completed application.
- Prepare project documentation.
- Upload the source code to GitHub.
- Publish the application if possible.

## 7. Completion Criteria

The project will be considered complete when the following requirements are met:

- [✔] Users can add, edit and delete household appliances.
- [ ] Users can create maintenance tasks and assign due dates.
- [ ] Users can mark maintenance tasks as completed.
- [ ] Users can record appliance repairs and associated costs.
- [ ] The dashboard displays relevant appliance and maintenance information.
- [ ] Application data is saved and remains available after refreshing the browser.
- [ ] The application has a functional and user-friendly interface.
- [ ] The application works on both desktop and mobile devices.
- [ ] The main functionality has been tested and works as expected.
- [ ] Project documentation is available in the GitHub repository.
